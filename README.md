# Cinari Website

Multi-page static website for Cinari.

## Deploy to GitHub Pages

1. Create a repository (for example `cinari-website`) on GitHub.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. GitHub will provide a free `github.io` address.

The website links the main GitHub buttons to:
`https://github.com/cinariengines/cinari.git`

The supplied Cinari logo is stored at `assets/cinari-logo.jpg`.
